광전 효과 (Photoelectric Effect)

1. 실험 이론 및 지배 방정식

빛의 입자성(광자 모델)을 검증하고 플랑크 상수(h)와 금속의 일함수(phi)를 측정합니다. 광자 에너지 E = hf 가 금속의 일함수 phi 보다 크면 광전자가 방출되며, 저지전압 V를 인가하여 광전류가 0이 되는 지점을 측정합니다 (eV = hf - phi).

  • K_max = E - phi = hf - phi
  • eV_0 = hf - phi
  • V_0 = (h / e) * f - (phi / e)
  • f_cutoff = phi / h

4. 단계별 실험 절차 (Step-by-Step Guide)

단계 1

장비 설치 및 예열

트랙 위에 수은 램프와 포토다이오드를 35cm 간격으로 설치하고, 수은 램프를 10분 이상 충분히 예열합니다.

⚠️ 주의사항: 수은 램프에서 방출되는 자외선 불빛을 맨눈으로 직접 응시하지 마십시오.
⚙️ Capstone 제어 동작: Capstone에서 EX-5549A Photoelectric Effect 템플릿을 열거나 아날로그 채널 A/B를 설정합니다.
✅ 검증 기준: 수은 램프가 안정적으로 켜져 있고 채널 A/B 케이블이 인터페이스에 단단히 결합되어 있는지 확인합니다.
단계 2

전류 증폭기 영점 교정 (Calibration)

DC 전류 증폭기의 CURRENT RANGES 스위치를 10^-13 A로 설정하고, SIGNAL 버튼을 눌러 Calibration 모드에서 0.000 A가 되도록 노브를 조절합니다.

⚠️ 주의사항: 실험 도중 전류 증폭기의 게인이나 영점 노브를 건드리지 마십시오.
⚙️ Capstone 제어 동작: SIGNAL 버튼을 다시 눌러 Measure 모드로 전환합니다.
✅ 검증 기준: 암실/빛 차단 상태에서 전류계 표시창이 0.000 A에 머무르는지 확인합니다.
단계 3

파장별 저지전압 측정 및 Keep Sample

조리개를 8mm, 필터를 365nm(8.219 x 10^14 Hz)에 맞추고 Capstone 하단의 Preview를 클릭합니다. 전류가 정확히 0이 될 때까지 전원 공급기 전압 손잡이를 미세 조절한 후 Keep Sample을 누릅니다.

⚠️ 주의사항: 전압 노브를 급격하게 돌리지 말고 천천히 0A 지점을 찾습니다.
⚙️ Capstone 제어 동작: 각 파장(365, 405, 436, 546, 577 nm)에 대해 저지전압을 표에 순차적으로 기록합니다.
✅ 검증 기준: 단파장(365nm)일수록 높은 저지전압(음의 전위차 크기 증가)이 나타나는지 확인합니다.
단계 4

선형 회귀 및 플랑크 상수(h) 산출

Capstone 그래프에서 저지전압 vs 진동수(V vs f) 데이터를 선형 피팅(Linear Fit: y = mx + b)합니다.

⚠️ 주의사항: 데이터 이상치가 있는 경우 특정 회차의 샘플을 재측정합니다.
⚙️ Capstone 제어 동작: 그래프 맞춤 도구상자에서 Linear Fit을 적용하고 기울기(m)와 y절편(b)을 확인합니다.
✅ 검증 기준: 기울기 m = h/e 이므로, h = m * 1.602 x 10^-19 J·s가 공인값(6.626 x 10^-34 J·s)과 오차 10% 이내인지 검증합니다.
단계 5

빛의 세기별 저지전압 불변성 검증

필터를 436nm로 고정한 후, 조리개 직경을 2mm, 4mm, 8mm로 변경하며 저지전압을 측정합니다.

⚠️ 주의사항: 조리개 휠을 회전할 때 광학 트랙 정렬이 흐트러지지 않도록 주의합니다.
⚙️ Capstone 제어 동작: 조리개 구경에 따라 광전류 크기는 변하지만 저지전압은 일정함을 확인합니다.
✅ 검증 기준: 빛의 세기가 증가해도 저지전압이 변하지 않는 입자성(광양자설)의 핵심 증거를 확인합니다.

5. 형성 평가 인터랙티브 퀴즈 (Interactive Quiz Widget)

문항 1 광전 효과 실험에서 빛의 진동수를 증가시키면 방출되는 전자의 어떤 물리량이 증가합니까?
💡 해설: E = hf - phi 이므로 진동수가 증가하면 광전자의 최대 운동 에너지가 선형적으로 증가합니다.
문항 2 저지전압(V) 대 진동수(f) 그래프에서 직선의 기울기가 나타내는 물리적 의미는 무엇입니까?
💡 해설: 식 V = (h/e)f - (phi/e) 로부터 기울기는 h/e를 직접 나타냅니다.
