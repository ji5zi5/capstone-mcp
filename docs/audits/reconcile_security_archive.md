# 로컬 연결·파일 경로·아카이브 감사 대조

루프백 리스너의 소유 확인, 훅 콜백의 수명, 네이티브 저장 전 경로 검사, ZIP 멤버와 XML 크기 제한을 검토했다. 네이티브 저장 시 대화상자 입력과 파일 생성 사이에는 외부 프로세스가 파일을 만들 수 있다.

기준은 upstream `c57410e` 및 근거 열의 수정 PR이다. 조사 이슈 [#140](https://github.com/ji5zi5/capstone-mcp/issues/140), 구현 에픽 [#124](https://github.com/ji5zi5/capstone-mcp/issues/124). 원장의 수정 상태에는 링크된 PR에 제출된 변경이 포함된다. [판정 기준과 남은 작업](RECONCILIATION_2026-11-27.md)
