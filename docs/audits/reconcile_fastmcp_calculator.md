# FastMCP·도구 라우터·계산기 감사 대조

stdio, HTTP 세션의 수명, 구조화 오류 및 계산기 입력 검증을 대조했다. 설치된 수식 엔진이 수식을 승인했다는 결론에는 해당 앱의 명시적 응답이 필요하다.

기준은 upstream `c57410e` 및 근거 열의 수정 PR이다. 조사 이슈 [#143](https://github.com/ji5zi5/capstone-mcp/issues/143), 구현 에픽 [#127](https://github.com/ji5zi5/capstone-mcp/issues/127). 원장의 수정 상태에는 링크된 PR에 제출된 변경이 포함된다. [판정 기준과 남은 작업](RECONCILIATION_2026-11-27.md)
