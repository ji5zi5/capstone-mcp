# 파일·다국어·테스트 감사 대조

실험 폴더를 하위 경로까지 읽어 .cap 36개, 데이터셋 332개, 종속 표본 119,295개와 저장 그래프 94개를 조사했다. 데이터셋이 없는 설정 파일은 18개다. 원본 해시는 전후 일치했다. CI는 비공개 실험 파일과 별개로 공개 가능한 합성 사례와 실제 stdio를 실행한다.

기준은 upstream `c57410e` 및 근거 열의 수정 PR이다. 조사 이슈 [#146](https://github.com/ji5zi5/capstone-mcp/issues/146), 구현 에픽 [#130](https://github.com/ji5zi5/capstone-mcp/issues/130). 원장의 수정 상태에는 링크된 PR에 제출된 변경이 포함된다. [판정 기준과 남은 작업](RECONCILIATION_2026-11-27.md)

## 네이티브 라벨과 AutomationId

파일 명령의 안정된 ID를 먼저 찾는다. 메뉴 제목과 일부 Qt 자식의 AutomationId는 비어 있을 수 있다. 설치 리소스나 호출자가 스냅샷에서 관측한 workflow_labels를 정확하게 대조한다. 잘린 스냅샷 또는 여러 후보에서는 입력하지 않는다. 제공 파일의 단일 세그먼트에서 관측한 종속/독립 StorageType 조합은 0/1이 264건, 7/4가 68건이다. [실물 관측과 판단](../remediation-verification.md) [공개 필드 계약](ROUND3_FILE_LABELS.md)
