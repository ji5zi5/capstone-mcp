# UIA·런·디스플레이·워크북 감사 대조

참조는 새 스냅샷을 얻으면 갱신된다. 입력 후에는 같은 대상을 새 참조로 찾고 완료 상태를 관측한다. 삭제 경로는 Capstone의 Delete Last Run 버튼이며, 임의 이름을 받아 해당 런을 삭제하는 명령은 확인되지 않았다.

기준은 upstream `c57410e` 및 근거 열의 수정 PR이다. 조사 이슈 [#144](https://github.com/ji5zi5/capstone-mcp/issues/144), 구현 에픽 [#128](https://github.com/ji5zi5/capstone-mcp/issues/128). 원장의 수정 상태에는 링크된 PR에 제출된 변경이 포함된다. [판정 기준과 남은 작업](RECONCILIATION_2026-11-27.md)
