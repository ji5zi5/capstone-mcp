# 통신·텔레메트리·계측기 감사 대조

설치 앱에서 확인 가능한 장치 목록/단일 측정 읽기, 호스트 시계, 실시간 이력과 보존 정책을 구별했다. RequestSetSamplingRate, RequestConfigureSensor, 측정 블록 읽기 및 하드웨어 타임스탬프는 확인한 JavaScript 래퍼에서 찾지 못했다.

기준은 upstream `c57410e` 및 근거 열의 수정 PR이다. 조사 이슈 [#142](https://github.com/ji5zi5/capstone-mcp/issues/142), 구현 에픽 [#126](https://github.com/ji5zi5/capstone-mcp/issues/126). 원장의 수정 상태에는 링크된 PR에 제출된 변경이 포함된다. [판정 기준과 남은 작업](RECONCILIATION_2026-11-27.md)
