# 물리 레시피·수치해석·보고서·RPC 감사 대조

실험에서 주어진 수치, 명시적 데모, 내부 시뮬레이션과 실제 장비 응답을 구별했다. 여러 측정 주기를 단일 단열 행정으로 간주하거나, 기준값이 없는 광학 측정을 명목 치수와 비교해서는 안 된다.

기준은 upstream `c57410e` 및 근거 열의 수정 PR이다. 조사 이슈 [#145](https://github.com/ji5zi5/capstone-mcp/issues/145), 구현 에픽 [#129](https://github.com/ji5zi5/capstone-mcp/issues/129). 원장의 수정 상태에는 링크된 PR에 제출된 변경이 포함된다. [판정 기준과 남은 작업](RECONCILIATION_2026-11-27.md)
